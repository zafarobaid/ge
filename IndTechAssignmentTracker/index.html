How to Run on Web & Mobile Phone

Access your DBA schedule from anywhere across all devices

Option 1: GitHub Pages (Free Hosting)

  1. Create a free account on GitHub.com.
  2. Create a new repository (e.g., dba-tracker).
  3. Upload this index.html file.
  4. Go to Settings → Pages, set branch to main, and click Save.
  5. Your site will be live at https://yourusername.github.io/dba-tracker!

Option 2: Vercel or Netlify (30-second Drag-and-Drop)

  1. Go to Vercel.com or Netlify.com.
  2. Drag and drop the folder containing this index.html file onto their dashboard.
  3. They will automatically deploy it and give you a live HTTPS link instantly.

Mobile App Shortcut (iOS / Android)

Once hosted online (or opened on mobile Safari/Chrome):

  • iPhone (Safari): Tap the Share button → Select "Add to Home Screen".
  • Android (Chrome): Tap the 3 dots menu → Select "Add to Home Screen" or "Install App".

It will launch like a native full-screen app on your phone with all your localStorage data intact!
